图片格式怎么选？

常见格式有 JPG、PNG、WebP、AVIF、GIF、SVG 等。选对格式，图片可以更清晰、文件更小，也能满足透明背景和动画等需求。

速览

用途 建议
照片 JPG
截图、Logo、图标、透明图片 PNG
网页图片 WebP（或 AVIF）
可缩放 Logo、图标、插画 SVG
简单动画 GIF / WebP
Windows 程序图标 ICO

一、常见图片格式一览

格式 主要特点 适合用途
JPG / JPEG 文件小，不支持透明背景 照片、风景图、普通图片
PNG 画质清晰，支持透明背景，文件通常较大 Logo、图标、截图、透明图片
WebP 文件较小，支持透明和动画 网站图片、网页背景、网络分享
AVIF 压缩率高，画质好，支持透明和动画 网站图片、高清图片、追求小体积的场景
GIF 支持简单动画，但颜色有限（最多 256 色） 简单动画、表情包
SVG 矢量格式，放大不会失真 Logo、图标、简单图形
BMP 通常不压缩，文件较大 Windows 传统图像处理、特殊用途
TIFF 支持高质量图像，文件可能很大 印刷、扫描、专业图像处理
ICO Windows 图标格式，可包含多种尺寸 Windows 程序图标、快捷方式图标

二、按使用场景选格式

使用场景 推荐格式 原因
手机照片、风景照片 JPG 体积小，兼容性好
网页图片 WebP 体积小，画质好
网站 Logo SVG / PNG SVG 可缩放，PNG 支持透明
软件图标 ICO / PNG ICO 适合 Windows，PNG 通用
透明背景图片 PNG / WebP / AVIF 支持透明背景
动态表情、简单动画 GIF / WebP 支持动画
印刷、专业摄影 TIFF 适合高质量图像处理
网页插画、图标 SVG 放大不失真

三、几个容易混淆的问题

1. JPG 和 PNG 有什么区别

  • JPG：适合照片，文件通常更小，但反复保存可能损失画质。
  • PNG：适合文字、图标、截图和透明背景，PNG 压缩不会损失画质。

简单来说：照片选 JPG，Logo 和透明图片选 PNG。

2. WebP 和 JPG 有什么区别

WebP 是更现代的格式，通常在相近画质下文件更小，而且支持透明背景和动画。用于网站时通常优先考虑 WebP；但需要兼容旧软件或特殊设备时，JPG 兼容性更好。

3. PNG 和 SVG 有什么区别

  • PNG 是像素图片，放大后可能变模糊。
  • SVG 是矢量图片，可以任意缩放而不失真。

Logo、图标、简单图形优先考虑 SVG；照片不适合用 SVG。

4. GIF 和视频有什么区别

GIF 可以做简单动画，但颜色最多 256 种，压缩效率也不高。动画内容复杂或时间长时，用 MP4、WebM 等视频格式更合适。

四、实用建议

  1. 普通照片：JPG，兼容性好，文件也比较小。
  2. 网站图片：优先 WebP，也可以考虑 AVIF。
  3. 透明背景：PNG，或支持透明的 WebP、AVIF。
  4. Logo 和图标：优先 SVG，需要普通图片时用 PNG。
  5. 简单动画：GIF 或 WebP。
  6. Windows 程序图标：ICO。
  7. 专业印刷：TIFF，具体以印刷要求为准。

五、与 RectIcon 的关系

  • RectIcon 生成 PNG 图片，适合截图、图标和透明背景。
  • 拖入 WEBP 图片可以快速转成 PNG，方便统一使用。
  • 程序图标请使用 多重导出 生成的多尺寸 PNG 与 favicon.ico。

六、总结

日常使用掌握这几个就足够：

  • JPG：照片
  • PNG：透明图片、截图、Logo
  • WebP：网页图片，兼顾画质和体积
  • SVG：矢量图标和 Logo
  • GIF：简单动画
  • ICO：Windows 图标

最重要的是：根据用途选择格式，而不是一味追求文件最小或画质最高。
