MS 画图 键盘快捷键

Windows 10 / Windows 11 上 Microsoft 画图（MS Paint）的实用速查：涵盖标准快捷键、不常见的操作、选区控制、绘图修饰键、图片属性与视图导航。

1. 文件与文档操作

快捷键 操作 说明
Ctrl + N 新建 创建一张新图片
Ctrl + O 打开 打开已有图片
Ctrl + S 保存 保存当前修改
F12 另存为 保存为新文件
Ctrl + P 打印 打开打印对话框
Alt + F4 退出 关闭画图
Ctrl + E 图片属性 打开图片属性，可设置宽度、高度与单位
Ctrl + W 调整大小和扭曲 打开缩放与倾斜对话框

2. 编辑操作

快捷键 操作 说明
Ctrl + Z 撤销 撤销上一步操作
Ctrl + Y 重做 重做刚刚撤销的操作
Ctrl + X 剪切 剪切选中的内容
Ctrl + C 复制 复制选中的内容
Ctrl + V 粘贴 粘贴剪切板内容
Delete 删除 删除选中的内容
Esc 取消 取消当前选区或操作
Shift + F10 右键菜单 打开焦点项的右键菜单

3. 绘图与画笔操作

快捷键 操作 说明
Ctrl + + 加粗 画笔、线条或形状轮廓加粗 1 像素
Ctrl + - 变细 画笔、线条或形状轮廓减细 1 像素
Shift + 绘制 约束绘制 按工具不同，把线条或形状约束为正角或等比例
Esc 取消绘制 取消尚未完成的绘制

4. 容易混淆的重要快捷键

快捷键 改变什么 不做什么
Ctrl + E 图片属性与画布尺寸 不会按比例缩放图片
Ctrl + W 通过缩放与倾斜改变图片尺寸 不是简单地改变屏幕显示比例
Ctrl + R 标尺的显示与隐藏 不会旋转图片
Ctrl + G 网格线的显示与隐藏 不会把对象编组
F11 全屏 以全屏模式查看图片

注意： 缩放（Zoom）只改变屏幕上的显示方式，不会改变图片的实际像素尺寸。
