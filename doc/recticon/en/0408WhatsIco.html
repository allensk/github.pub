What is an ICO icon?

.ico is the common Windows icon file format, used to show the icons of software, folders, shortcuts and programs.

The biggest difference from ordinary pictures: one ICO file can hold many sizes of the image at once, and Windows picks the right one for each display situation.

At a glance

Question Answer
How many images in one ICO Several, one per size
Recommended sizes 16, 24, 32, 48, 256 px
Recommended color format 32-bit RGBA (with Alpha transparency)
How is 256 × 256 stored Usually PNG encoded inside the ICO

I. Where ICO is used

  • Software icons: EXE programs, desktop, start menu
  • Folder icons: custom folder looks
  • Shortcut icons: desktop and other shortcuts
  • Taskbar icons: taskbar and system tray
  • File type icons: representing a kind of file

Simply put, ICO is the dedicated picture format Windows uses to show all kinds of icons.

II. Which sizes can an ICO contain

The minimal recommended set (5 sizes)

Size Common use
16 × 16 Small icons, system tray
24 × 24 Small icons in high DPI environments
32 × 32 Normal window icons, taskbar
48 × 48 Desktop and larger icon display
256 × 256 High resolution display, large icons

All sizes are in pixels (px). These five sizes are the minimal recommended set for Windows application icons and cover most common display situations.

Optional sizes

Size Good for
64 × 64 Larger icon display
128 × 128 High resolution icon display

These sizes are not required, add them by software and real world needs.

Note: the 256 × 256 image is usually stored PNG encoded inside the ICO file.

III. Why one ICO holds several pictures

This is the most important trait of the ICO format.

For example one ICO holds 16 × 16, 24 × 24, 32 × 32, 48 × 48 and 256 × 256: they all belong to the same icon, but each one can be designed and optimized for its size.

Windows picks the best fitting image for the actual display, instead of endlessly enlarging one small picture — that is what keeps icons sharp and free of jagged edges.

IV. Colors and transparency

ICO supports ordinary pictures as well as transparent backgrounds, the common specs:

Item Support
Color depth 1-bit, 4-bit, 8-bit, 24-bit, 32-bit
Transparent background Alpha channel, blends naturally with the desktop
PNG images A PNG image can be put straight into the ICO file

For modern Windows software, 32-bit color + Alpha transparency (RGBA) gives the best color and transparency results.

V. Things to watch when making an ICO

  1. Use a square picture: width and height should match.
  2. Prefer a transparent background: avoids ugly white blocks around the icon.
  3. Include the common sizes: at least the five of the minimal recommended set.
  4. High quality for 256 × 256: the big icon must survive high resolution displays.
  5. Optimize the small sizes separately: 16 × 16 and 24 × 24 have little space, complex designs blur into a smear.

VI. Recommended ICO file specs

Item Recommendation
File format ICO
Minimal recommended size set 16, 24, 32, 48, 256 px
Color depth 32-bit RGBA
Background Transparency supported
256 × 256 image PNG encoding supported
File content One file holding several sizes

For higher resolutions or special needs, sizes like 64 × 64 and 128 × 128 can be added.

VII. How this relates to RectIcon

RectIcon’s multi export (Tools menu) exports several PNG sizes in one go and generates a 32 × 32 favicon.ico, which covers the common icon making needs.

VIII. Summary

An ICO is not just one picture, it is an icon file that can hold images in several sizes.

When making a Windows software icon there is no need to pile up sizes: prepare the recommended minimal set of 16 × 16, 24 × 24, 32 × 32, 48 × 48 and 256 × 256 and most scenarios are covered.
