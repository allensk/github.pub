Load selection

Load the selection from when the program was last closed

Undo

For the built-in editor. Double-click the image area and the built-in editor opens, confirm your changes there and they replace the current picture. Back in the main window, Undo restores the picture from before the edit, which makes built-in editing and recovery easy

Square mode

Square mode, landscape mode, portrait mode, three fixed pixel selections

To reduce the differences image scaling causes, the software limits freeform scaling

Settings

The current options are

  • use the clipboard
    a screenshot is copied to the clipboard automatically, note that this may overwrite the previous clipboard content, use it carefully
  • pick the external editor
    choose the external editor used to edit images
  • create a desktop shortcut

Reset / repair

Try this option when the software has a problem, normally do not choose it
