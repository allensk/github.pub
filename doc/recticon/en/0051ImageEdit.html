Edit

External editing

  • MS Paint
    Windows Paint
  • MS Paint3D
    Windows 3D Paint

After editing with an external graphics editor, please save the graphics with Ctrl + S and close the external graphics editor

When you try an external graphics editor, make sure the save path does not change, if the path changes RectIcon will not update the saved picture

  • ✓ with MS Paint any edit is updated
  • ✓ simple touch-ups in MS Paint3D are updated
  • ✘ MS Paint3D when it asks to save as
  • ✘ for example when MS Paint3D opens a transparent background it asks to save as, in this case RectIcon will not update
#
Built-in editing

View

Double-click to view a picture and open the built-in editor

Crop

Crop by ratio, the ratio follows the width/height ratio of the selection

Zoom

Zoom the picture, the size follows the selection

Transparency

Make the background transparent, pick a color and adjust the deviation

You can do all of this one after another and undo the edits with the Undo menu
