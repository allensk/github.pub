What is DPI?

DPI stands for Dots Per Inch, it describes the dot density of a display or a print.

In Windows desktop programs, DPI is more often used as another word for the interface scaling ratio: the system uses DPI to decide how big windows, buttons, text, icons and pictures appear.

At a glance

Question Answer
What is 96 DPI The traditional Windows baseline, i.e. 100% scaling
How to compute scaling Scaling = DPI / 96
Does DPI change picture pixels No, it only affects display and print physical size
Is DPI the same as screen resolution No, resolution counts total pixels

I. What does 96 DPI mean

Windows uses 96 DPI as the traditional standard baseline, which is 100% scaling. The common pairs are:

DPI Scaling Windows display setting
96 100% 100% (recommended)
120 125% 125%
144 150% 150%
192 200% 200%

The formula:

Scaling = DPI / 96

For example 144 DPI: 144 / 96 = 1.5, that is 150% scaling.

II. How DPI affects interface size

Take a window with a logical size of 800 × 600 (its size at 100%):

DPI Scaling Actual display size
96 100% 800 × 600 px
120 125% 1000 × 750 px
144 150% 1200 × 900 px
192 200% 1600 × 1200 px

The higher the DPI, the bigger the interface elements appear. The point is that screens with different resolutions and pixel densities all get a comfortable display, instead of buttons and text becoming tiny on high DPI screens.

III. DPI, resolution and PPI

Name Meaning Example
Resolution How many pixels there are 1920 × 1080
DPI The scaling baseline used to draw the interface 96 DPI, 144 DPI
PPI (Pixels Per Inch) The physical pixel density of the screen Same size, higher resolution → higher PPI

Two 1920 × 1080 monitors with different physical sizes have different PPI; Windows DPI scaling adjusts program interfaces to a comfortable visual size.

IV. Does DPI change the pixels of a picture

No. An 800 × 600 pixel picture marked 96 DPI or 300 DPI still has 800 × 600 pixels.

DPI only affects the print (physical) size computed from it:

Physical size (inches) = pixel count / DPI

For an 800 pixel wide picture:

  • 96 DPI: about 8.33 inches
  • 300 DPI: about 2.67 inches

How big it looks on screen also depends on how the program itself handles DPI.

V. How this relates to RectIcon

  • RectIcon fits Windows scaling from 100% to 200%.
  • A capture is made of screen pixels, the screen scaling directly affects the screen area the selection covers.
  • To reduce the differences scaling causes, RectIcon limits freeform scaling of the selection and offers fixed ratio modes such as square, landscape and portrait.

VI. Summary

  • 96 DPI is the traditional 100% scaling baseline of Windows.
  • Higher DPI means bigger interface elements.
  • DPI does not change picture pixels, only the computed size.
  • DPI is not resolution, they describe different things.
  • Handling DPI properly keeps the program displaying well at 100%, 125%, 150%, 200% and other scaling levels.
