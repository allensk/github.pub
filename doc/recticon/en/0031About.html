About

RectIcon - capture, edit and export graphics, fast

RectIcon focuses on well-formed pictures keeping your pictures consistent, which helps to later use, collect and process them

!!! (the software is maintained only) !!!

Free software

The software is free to use, the graphics you create belong to you, the software never uploads your images on its own and never uploads information on its own (your online actions of the software are used to improve it)

Goals of the software

  • Single
    The software is a single executable file, its content is easy to see, it is easy to copy and delete
  • Fast
    Focused on the features, aiming for convenient operation and quick use
  • Straightforward
    What you see is what you get (WYSIWYG)
  • Clean
    No viruses, all files are put in the directories the system assigns, it can be used offline. (Online it updates itself, the global hotkey hooks the keyboard)

Where the software comes from

On Jun 20, 2021, while building a game of my own (learning only), I needed many icons.

Using the view of the 3D model itself avoids creating icons, which involves the old complex picture processing flow:

  1. adjust the camera angle, render
  2. export the render
  3. import the picture into an image editor, adjust it
  4. pick a path, type a name, export the format and size I needed
  5. export

So I wrote a handy little tool (RectIcon) that helps users quickly capture graphics and create icons, it only needs

  1. adjust the camera angle, render
  2. capture
  3. export, rename

RectIcon also fits flat screenshots and desktop screenshots, avoiding complex operations.
