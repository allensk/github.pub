MS Paint — Keyboard Shortcuts

A practical reference for Microsoft Paint on Windows 10 and Windows 11, covering standard shortcuts, less obvious operations, selection controls, drawing modifiers, image properties and navigation.

1. File and Document Operations

Shortcut Operation Description
Ctrl + N New Create a new image
Ctrl + O Open Open an existing image
Ctrl + S Save Save current changes
F12 Save As Save as a new file
Ctrl + P Print Open print dialog
Alt + F4 Exit Close Paint
Ctrl + E Image Properties Open image properties, including width, height and units
Ctrl + W Resize and Skew Open image resizing and skewing dialog

2. Editing Operations

Shortcut Operation Description
Ctrl + Z Undo Undo last operation
Ctrl + Y Redo Redo previously undone operation
Ctrl + X Cut Cut selected content
Ctrl + C Copy Copy selected content
Ctrl + V Paste Paste clipboard content
Delete Delete Delete selected content
Esc Cancel Cancel current selection or operation
Shift + F10 Context Menu Open the context menu for the focused item

3. Drawing and Brush Operations

Shortcut Operation Description
Ctrl + + Increase Width Increase brush, line or shape outline width by one pixel
Ctrl + - Decrease Width Decrease brush, line or shape outline width by one pixel
Shift + draw Constrain Drawing Constrain certain lines or shapes to regular angles or proportions, depending on the tool
Esc Cancel Drawing Cancel an unfinished drawing operation

4. Important Shortcuts That Are Easy to Confuse

Shortcut What it changes What it does NOT do
Ctrl + E Image properties and canvas dimensions Does not proportionally scale the image
Ctrl + W Image dimensions through resizing and skewing Does not simply change screen zoom
Ctrl + R Ruler visibility Does not rotate the image
Ctrl + G Gridline visibility Does not group objects
F11 Full Screen View the picture in full-screen mode

Important: Zoom only changes how the image is displayed on screen. It does not change the actual image dimensions.
