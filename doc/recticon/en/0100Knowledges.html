Lossless

PNG is lossless compression, JPEG is lossy compression

The advantage of JPEG is that it takes up very little space.

Distortion

There are mainly two types of pictures, raster and vector, each with its own advantages.

While vector graphics can be scaled freely, scaling a raster picture causes distortion.

A raster picture is a series of points (Pixel); take a computer monitor, the naked eye sometimes sees a graininess on the screen and those points are the pixels of the screen. A resolution of 1920 * 1080 means there are 1920 points horizontally and 1080 points vertically, and these points make up the screen picture, phone screens work the same way.

When shrinking a raster picture, for example 512 * 512 down to 256 * 256, the set of points gets smaller, data is lost and it cannot be restored to the original picture, which is distortion.

When enlarging a raster picture, for example 3 * 3 to 4 * 4, 4 points horizontally cannot go back to 3 points, which is distortion; with the same algorithm, 4 * 4 can go back to 3 * 3.
