MS 画图 实用场景

Windows 10 / Windows 11 上用 Microsoft 画图（MS Paint）处理日常图片的简明指南。

1. 画布与图片尺寸

先分清三个不同的概念：

概念 含义
图片尺寸 图片实际的像素尺寸
画布尺寸 工作区域的宽度与高度
缩放 屏幕上的放大倍数，不改变图片数据

修改画布尺寸

用途： 增加空白、去掉边距，或制作精确尺寸的图片。

  1. 按 Ctrl + E 打开图片属性。
  2. 选择像素、英寸或厘米。
  3. 输入需要的宽度与高度。
  4. 确认修改。

示例：把 800 × 600 的画布改为 1200 × 900。

也可以直接拖动画布边界的控制点快速调整。

缩放图片

用途： 缩放图片的实际内容。

  1. 按 Ctrl + W 打开调整大小和扭曲。
  2. 选择百分比或像素。
  3. 输入新的尺寸。
  4. 保持勾选“保持纵横比”，避免变形。
  5. 确认。

示例：把 1920 × 1080 缩小为 800 × 450。

旋转、翻转与倾斜

用途： 改变图片方向，或做简单的形变。

  • 用旋转可旋转 90° 或 180°。
  • 用水平翻转、垂直翻转可镜像图片。
  • 用 Ctrl + W 可做水平或垂直倾斜。

2. 裁剪、选择与移动

用途： 提取图片区域、去掉不需要的内容，或移动元素。

操作 做法
矩形选择 在目标区域上拖拽
自由图形选择 沿不规则区域描画
裁剪 选中区域后点“裁剪”
复制 选中后按 Ctrl + C
剪切 选中后按 Ctrl + X
粘贴 按 Ctrl + V
删除 选中后按 Delete
移动 拖动选中的区域
精确移动 在支持时使用方向键

透明选择： 在选择选项中启用后，移动或复制内容时会忽略选中的背景色。它不等于专业的背景去除，也不是完整的 Alpha 通道遮罩。

典型用途：

  • 从截图中提取按钮或图标。
  • 去掉不需要的边框。
  • 把图形移动到别的位置。
  • 复制对象并去掉它周围的纯色背景。

3. 绘图与标注

用途： 突出重要内容，或画简单插图。

工具 用途
铅笔 / 画笔 自由绘制
矩形 / 椭圆 圈出区域、绘制形状
直线 / 箭头 指示位置或方向
文本（A） 添加标注与说明
橡皮擦 去掉不需要的痕迹
填充 给封闭区域填色

实用技巧

  • 矩形轮廓用“无填充”，只保留边框。
  • 调整“粗细”控制线条的宽度。
  • 绘制支持的形状时按住 Shift 可约束为等比例。
  • 用红色矩形和箭头，可以做出清晰的截图说明。
  • 在文本框外点击一下，即可结束文字编辑。

示例流程：截图标注

  1. 打开一张截图。
  2. 裁掉不需要的内容。
  3. 用红色矩形圈出重要控件。
  4. 加上箭头与说明文字。
  5. 保存为 PNG。

4. 颜色操作

用途： 复用颜色、替换颜色与填色。

拾取颜色

  1. 选择“颜色选取器”（吸管）。
  2. 点击图片中的某个像素。
  3. 用取到的颜色继续绘制。

填充或替换背景

  1. 选择“用颜色填充”。
  2. 选择要替换成的颜色。
  3. 点击目标区域。

这种方式最适合封闭区域和纯色背景。如果有缺口，填充可能扩散到相邻区域。

典型用途：

  • 给简单图形换背景色。
  • 让标注颜色保持一致。
  • 制作简单的配色。

5. 保存与转换图片格式

用途： 保住画质，或减小文件体积。

用 文件 → 另存为 选择输出格式。

格式 推荐用途
PNG 截图、图标与图形；支持透明度
JPEG 照片，文件相对更小
BMP 传统位图存储
GIF 颜色有限的静态图形；画图不会保留动图的动画流程
TIFF 高质量图片存储与扫描流程

注意：

  • JPEG 使用有损压缩，且不支持透明度。
  • 截图和图形一般优先用 PNG。
  • 传统画图的透明编辑能力有限。

6. 实用工作流

创建指定尺寸的图片

  1. 新建图片。
  2. 按 Ctrl + E。
  3. 用像素设置需要的宽度与高度。
  4. 绘制或粘贴内容。
  5. 保存为 PNG。

给现有图片加边距

  1. 打开图片。
  2. 按 Ctrl + E。
  3. 增大画布尺寸。
  4. 确认并检查新增的空白。
  5. 必要时重新摆放画面。

从截图中提取 UI 元素

  1. 打开截图。
  2. 放大以便精确操作。
  3. 选中需要的区域。
  4. 裁剪图片。
  5. 保存为 PNG。

创建一个简单图标

  1. 新建正方形画布。
  2. 设置需要的像素尺寸。
  3. 需要时打开网格线。
  4. 用简单形状绘制。
  5. 放大做像素级修改。
  6. 保存为 PNG。

制作透明背景图形

仅 Win11

  1. 使用支持透明画布背景的画图版本。
  2. 启用透明画布选项。
  3. 绘制图形。
  4. 保存为 PNG。
  5. 重新打开文件，确认透明效果。

说明：经典画图里的“透明选择”与透明画布不是一回事。

7. 快速操作参考

目标 推荐操作
改变画布尺寸 Ctrl + E
缩放图片内容 Ctrl + W
去掉不需要的区域 裁剪
提取不规则对象 自由图形选择
移动画面内容 选择 + 拖拽
突出重要信息 矩形 + 箭头
添加说明 文本工具
复用已有颜色 颜色选取器
填充背景 用颜色填充
镜像图片 翻转
修正图片方向 旋转
改变屏幕显示比例 缩放
保留图片透明 用支持透明画布的版本保存 PNG

提示： 编辑重要图片前，先“另存为”一份副本。这样能保住原图，试验也更放心。

画图很适合快速改图、截图、标注、裁剪和制作简单图形；需要图层、遮罩与专业合成时，请使用专门的图形软件。
