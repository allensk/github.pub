Chat Keeper

收藏有价值的 AI 对话，让知识持续积累。

Chat Keeper 是一款面向通义千问用户的 Chrome 扩展，帮助你保存、查找、整理和回顾自己的问答。

🔒 本地存储，注重隐私。
📖 清晰阅读，方便回顾。
⚙️ 简单易用，专注对话管理。
